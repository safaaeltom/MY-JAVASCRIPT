# My JavaScript Journey

This repository documents my journey of learning JavaScript from the fundamentals to more advanced concepts.

The goal of this project is not only to learn JavaScript syntax, but to deeply understand how JavaScript works and how to apply its concepts in real projects and interactive web applications.

## What I'm Doing

I am learning JavaScript step by step through:
- practicing concepts after each lesson
- experimenting with code to understand behavior
- organizing topics into separate folders
- committing progress regularly for revision and tracking

Each folder in this repository focuses on a specific JavaScript topic.

## Topics Covered So Far

- Variables and Data Types
- Strings
- Numbers and Operators
- Arrays and Array Methods
- Booleans and Comparison Operators
- Conditional Statements
- Loops
- Switch Statements

More topics will continue to be added as I progress.

## Purpose of This Repository

This repository serves as:
- a personal learning archive
- a revision resource
- a place to practice JavaScript concepts
- a record of my progress as I improve my programming skills

## Learning Approach

I believe the best way to learn programming is through:
- consistency
- repetition
- practice
- debugging
- building understanding instead of memorizing

This repository reflects that process.
